# Прототип

Мобильное приложение на Expo (React Native, TypeScript). Тринадцать экранов: онбординг, тарифы, вход, регистрация, код подтверждения, чаты, переписка, настройки, а также новый аккаунт, установка пароля и главная.

## Запуск

```
npm install
npx expo install react react-native react-native-safe-area-context @expo/vector-icons
npx expo start
```

В терминале появится QR-код. Откройте его в приложении Expo Go (на iPhone — камерой). Телефон и компьютер должны быть в одной сети Wi-Fi. Если не подключается, запустите `npx expo start --tunnel`.

Список всех экранов открывается долгим нажатием на картинку на первом экране.
